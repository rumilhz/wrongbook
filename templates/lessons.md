# 错题本（lessons.md）—— 前置防错禁则清单

> 这是 Agent 的"老师笔记"。不是故障字典：这些条目存在的意义是让你
> **动手写之前**看到，而不是报错之后回来翻。
>
> 维护规则：
> - 一条一行，格式 `禁止 X —— 因为会 Y`（+ 可选备注）
> - 同类错误第二次出现 → 扩充那一条（加示例/变体），不新建
> - 只沉淀通用/可复现的模式，一次性环境噪音不存
> - 定期修剪：合并重复、删除过时

## 高频铁律（与常驻指令文件同步，≤5 条）

- [shell] 禁止直接 `ls`/操作可能不存在的路径 —— 因为 exit 2 会让整条命令判 failed（即使 `2>/dev/null` 吞了报错文本）；写法 `[ -d p ] && ls p`
- [shell/Windows] 禁止把 MSYS/WSL 路径（`/tmp`、`/mnt/d/...`）直接传给 Windows 程序 —— 因为路径映射不一致会**报成功但实际没写文件**；先 `cygpath -w` 转 Windows 路径
- [shell] 禁止用未加引号定界符的 heredoc 写含 `\n`/`$` 的内容 —— 因为 shell 会展开转义和变量导致内容变形；用 `<<'EOF'`
- [shell/PowerShell] 禁止在 bash 双引号内嵌含 `$_` 的 `powershell -Command "..."` —— 因为 `$_` 会被 bash 当变量展开吞掉 → 命令损坏 exit 1；写 `.ps1` 脚本执行（UTF-8 编码保中文），或整串用**单引号**包裹

## 全部禁则（按领域分类）

### shell / 命令执行

- （示例）禁止把未引用的含空格路径作为单个参数 —— 因为会被拆成多个参数；始终加引号
- （示例）禁止用 `echo` 写多行含特殊字符的文件 —— 因为转义地狱；改用 `cat <<'EOF'`

### 安装 / 依赖

- （示例）Python 包 requires_python 不匹配 / 镜像缺包时禁止硬 pip —— 因为装不上且浪费时间；用 `uv tool install` 等隔离安装工具

### 平台 / 工具特定

- （示例）遇到平台安全模式先清理修复标记文件 —— 因为残留标记会让模式一直持续；检查 repair 目录

## 沉淀模板（复制下面的占位符来添加新条目）

```markdown
- [领域] 禁止 X —— 因为会 Y；预防性写法 Z
```

填写要点：
1. 领域标签用方括号，如 `[bash]` `[安装]` `[平台]`
2. 「禁止 X」写**预防性写法**（以后不这么写 / 必须这么写）
3. 「因为会 Y」写一行根因——这是判断"变体场景是否同类"的依据
4. 解决过程有非显然的坑（重启/清缓存/握手命令）才追加 `备注：...`
