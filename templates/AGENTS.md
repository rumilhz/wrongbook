# AGENTS.md —— 前置防错常驻指令模板（通用版）

> 适用：Claude Code（改名 CLAUDE.md）、Codex、Cursor、Reasonix（改名 REASONIX.md）、
> 以及其他支持"指令文件每轮加载"的 Agent 平台。
> 保持精简：本文件每轮全量加载，只放元规则 + 领域映射 + ≤5 条高频铁律；新增禁则只进 lessons.md。

## 元规则：动手前核对错题本（防错优先，不做事后纠错）

- **每次执行工具/命令、写代码、装包、调 API 之前**，按「动作类型 → 错题本领域」映射
  核对对应领域的禁则，命中即换预防性写法，**不等报错再纠错**。
- **可见核对动作（强制）**：每次调用 shell 工具前，回复里先写一行
  `[错题本核对] 领域=xx 无命中 / 命中禁则xx→改用yy`——让核对可被监督。
- **禁止豁免核对**：检查/验证/只读类命令（git status、lint、ls、wc 等）同样必须核对——
  因为检查命令一样会踩 exit code / 路径 / 编码坑。无任何豁免。
- 命令失败 / exit code 非 0 / 工具报错后：按「禁止 X —— 因为会 Y」格式沉淀或扩充错题本，
  不写长复盘。

## 动作类型 → 错题本领域 映射

| 动作 | 查哪些领域 |
|---|---|
| 执行 shell/命令 | [bash] [shell] [命令] [Windows] |
| 写代码/改文件 | [语言] [编码] [脚本] |
| 装包/改配置 | [安装] [配置] [依赖] |
| 调工具/API/MCP | [工具] [平台] [配额] |
| 路径/跨系统传文件 | [路径] [MSYS] [WSL] |

## 高频铁律（自动晋升区，≤5 条，随错题本换血）

> 以下为示例，替换为你自己最常踩的坑；规则：错题本中频率最高/最痛的条目自动晋升到这里，
> 新晋的挤掉旧的。完整清单在 lessons.md。

- 禁止在 shell 双引号内嵌含 `$` 特殊变量（如 `$_`）的另一语言命令串 —— 会被 shell 展开
  吞掉导致命令损坏；用单引号包裹或写成脚本文件。
- 禁止直接 `ls`/操作可能不存在的路径 —— exit 2 会让整条命令判 failed；先 `[ -d p ] &&` 判断。
- 禁止把 MSYS/WSL 路径（`/tmp`、`/mnt/d/...`）直接传给 Windows 程序 —— 路径映射不一致
  会**报成功但实际没写文件**；先 `cygpath -w` 转换。
- 禁止把可能无匹配的 `grep` 放在命令链末尾（不带兜底）—— 无匹配返回 exit 1 污染整条命令；
  加 `|| echo NO_MATCH` 或 `|| true`。
- 禁止常规抓取/单页查询直接用云端抓取服务（Firecrawl 等）—— 按 credits 计费、免费额度有限；
  先用内置免费抓取，需渲染/搜索聚合再升级。

## 沉淀格式（写进 lessons.md 时遵守）

```markdown
- [领域] 禁止 X —— 因为会 Y；预防性写法 Z
```

- 「禁止 X」是主体（以后不这么写 / 必须这么写）
- 「因为会 Y」留一行根因，用于判断变体场景是否同类
- 「如何解决」默认省略，只有解决过程有非显然的坑才追加备注
