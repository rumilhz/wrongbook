# AGENTS.md —— 前置防错常驻指令模板（通用版）

> 适用：Claude Code（改名 CLAUDE.md）、Codex、Cursor、Reasonix（改名 REASONIX.md）、
> 以及其他支持"指令文件每轮加载"的 Agent 平台。
> 保持精简：本文件每轮全量加载，只放元规则 + ≤5 条高频铁律，新增禁则只进 lessons.md。

## 元规则：写之前先查错题本（防错优先，不做事后纠错）

- 每次执行 shell/PowerShell 命令、写代码、安装包**之前**，先检索错题本
  （`lessons.md` 或平台的长期记忆），核对当前操作是否命中禁则；
  命中即用预防性写法，**不等报错再纠错**。
- 命令失败 / exit code 非 0 / 工具报错后：按「禁止 X —— 因为会 Y」格式
  沉淀或扩充错题本，不写长复盘。

## 高频铁律（最痛的 ≤5 条，错题本速览）

> 以下为示例条目，替换为你自己最常踩的坑。完整清单在 lessons.md。

- 禁止直接 `ls`/操作可能不存在的路径 —— exit 2 会让整条命令判 failed；
  先 `[ -d p ] &&` 判断再操作。
- 禁止在 shell 双引号内嵌含 `$` 特殊变量（如 `$_`）的另一语言命令串 ——
  会被 shell 展开吞掉导致命令损坏；用单引号包裹或写成脚本文件。
- 禁止把 MSYS/WSL 路径（`/tmp`、`/mnt/d/...`）直接传给 Windows 程序 ——
  路径映射不一致会**报成功但实际没写文件**；先 `cygpath -w` 转换。
- 禁止用未加引号定界符的 heredoc 写含 `\n`/`$` 的内容 —— shell 会展开
  转义和变量导致内容变形；用 `<<'EOF'`。

## 沉淀格式（写进 lessons.md 时遵守）

```markdown
- [领域] 禁止 X —— 因为会 Y；预防性写法 Z
```

- 「禁止 X」是主体（以后不这么写 / 必须这么写）
- 「因为会 Y」留一行根因，用于判断变体场景是否同类
- 「如何解决」默认省略，只有解决过程有非显然的坑才追加备注
