# 种子库（lessons.seed.md）—— 作者真实沉淀的禁则

> 这是本仓库作者在真实使用中沉淀的禁则（启动基线 9 条，2026-08）。
> 新用户把它复制进自己的错题本当种子，比从空模板开始更易上手。
>
> **怎么用**：
> 1. 通读一遍，**只保留你在用的领域**（比如你不用 Windows，[bash/Windows] 和 [bash/PowerShell] 可删）；
> 2. 保留后**把措辞改成你的环境的写法**（路径、工具名）；
> 3. 种子只是起点——真正的价值来自你接下来沉淀自己的坑。
>
> 每条标注了适用范围：`[通用]` 任何平台/语言适用；`[环境特定]` 只在标注环境下适用。

## 跨平台通用（建议全保留）

- [shell] 禁止直接 `ls`/操作可能不存在的路径 —— 因为 exit 2 会让整条命令判 failed（即使 `2>/dev/null` 吞了报错文本）；写法 `[ -d p ] && ls p`
- [shell] 禁止用未加引号定界符的 heredoc 写含 `\n`/`$` 的内容 —— 因为 shell 会展开转义和变量导致内容变形；用 `<<'EOF'`
- [shell] 禁止把含空格/特殊字符的路径不加引号使用 —— 因为会被拆成多个参数；始终加引号（变体：通配符场景除外，需刻意展开时）

## bash + Windows（MSYS/Git Bash 环境特定）

- [bash/Windows] 禁止把 MSYS 路径（`/tmp`、`/c/...` 等）直接传给 Windows 程序 —— 因为路径映射不一致会**报成功但实际没写文件**；先 `cygpath -w` 转 Windows 路径
- [bash/PowerShell] 禁止在 bash 双引号内嵌含 `$_` 的 `powershell -Command "..."` —— 因为 `$_` 会被 bash 当变量展开吞掉 → 命令损坏 exit 1；改写成 `.ps1` 脚本执行（UTF-8 编码保中文输出），或整串用**单引号**包裹让 bash 零展开

## 工具/平台特定（参考案例，按你的环境适配）

- [浏览器自动化] 禁止连续操作间隔 >2-3 秒或会话间等待 —— 因为 daemon 会清理空闲 session（`ConnectionRefused 1225`）；用 `&&` 串联连续操作（来源：BrowserAct）
- [安装] Python 包 requires_python 不匹配 / 镜像缺包时禁止硬 pip —— 因为 cp312-only 包装不上本机 3.13、镜像可能未同步；用 `uv tool install` 隔离装
- [WSL] 禁止把模型等大文件放 `/mnt/d` —— 因为 9P 读太慢；放 WSL 内部盘
- [文献管理] 禁止用 Web API 传 PDF —— 因为官方云配额用完即失败、本地 WebDAV 不拉官方云；必须用本地插件 import（来源：Zotero + 坚果云）
